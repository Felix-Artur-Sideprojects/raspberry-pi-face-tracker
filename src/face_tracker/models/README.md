# YuNet model

The application expects face_detection_yunet_2023mar.onnx in this directory.

The bundled weights come from the official
[OpenCV Model Zoo](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet).
They are distributed under the accompanying upstream [MIT licence](LICENSE).

Official download:
https://media.githubusercontent.com/media/opencv/opencv_zoo/main/models/face_detection_yunet/face_detection_yunet_2023mar.onnx
